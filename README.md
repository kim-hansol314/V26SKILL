# V26 스킬 계산기

원본(https://v26skill2.netlify.app/)과 같은 구조의 단일 페이지 웹앱.
**타자 / 선발 / 중계 / 마무리** 4개 탭, 스킬 레벨 **5~10**, 스킬 3슬롯 조합 →
총 렙합 · 총 점수합 · 상위 확률 · 등급 · 스킬변경권 기대 소모량 계산.
다크모드 토글과 스킬 등급별 글씨색을 지원합니다.

## 파일 구조

```
index.html         앱 본체 (React + Tailwind CDN, 빌드 불필요)
data/skills.js     ★ 스킬별 점수표 (여기만 고치면 됨)
data/positions.js  선발/중계/마무리 노출 규칙 (공식 확률표 기준)
data/grades.js     스킬 등급 + 등급별 글씨색
data/prob.js       카드타입별 상위 확률 분포표 + 계산 규칙
data/allstar.js    하단 올스타 확률표 (토글 3종)
data/batter.jpg    참고용 원본 점수표 이미지 (등급 색 출처)
data/pitcher.jpg
data/allstar_*.PNG 올스타 확률표 원본 이미지
```

## 실행

- `index.html` 을 브라우저로 그냥 열면 됩니다. (별도 서버 불필요)
- 배포: 이 폴더 전체를 Netlify 에 드래그&드롭 하면 끝. (정적 사이트)

## 1. 점수 수정하는 법

### 방법 A — 파일 직접 수정 (영구 반영)

`data/skills.js` 를 열어 값만 바꾸면 됩니다.

```js
window.SKILL_SCORES = {
  batter: [
    { name: "스위치히터(양타)", scores: { 5: 21.90, 6: 25.65, 7: 30.20, 8: 35.30, 9: 39.85, 10: 44.95 } },
    { name: "황금세대",         scores: { 5: 17.04, 6: 24.72, 7: null, 8: null, 9: null, 10: null } },
    ...
  ],
  pitcher: [ ... ],
};
```

- **`null`** = 해당 레벨이 없는 스킬 → 사이트에서 그 레벨 버튼이 자동 비활성화됩니다.
- 스킬 **추가/삭제**는 줄을 넣거나 지우면 됩니다. 목록 노출 순서 = 파일에 적힌 순서.
- 레벨 범위는 `window.SKILL_LEVELS`, 탭 구성은 `window.SKILL_TABS` 에서 변경합니다.

> **왜 선발/중계/마무리로 안 나눴나요?**
> 저니맨·철완·필승카드처럼 세 포지션 공통인 스킬이 3벌로 중복되면, 점수 하나 고칠 때 세 군데를 고쳐야 하고
> 값이 어긋나기 쉽습니다. 그래서 `pitcher` 한 벌만 두고 **화면에서 탭별로 걸러내는** 방식을 씁니다.
> 배치별 값이 다른 스킬은 이미 이름으로 구분되어 있습니다 (`마당쇠(불펜)`, `워크에식(중계)`, `수호신(셋업2)`).

### 방법 B — 사이트 안에서 편집 (엑셀 복붙)

우측 상단 **`점수표 편집`** 버튼 →

1. 엑셀/스프레드시트에서 표를 복사해 그대로 붙여넣기
   (열 순서: `스킬명 / 5 / 6 / 7 / 8 / 9 / 10`, 탭 또는 콤마 구분, 헤더행 있어도 됨)
2. **적용** → 즉시 반영 (이 브라우저에만 저장 / localStorage)
3. **skills.js 내려받기** → 받은 파일로 `data/skills.js` 교체 시 영구 반영
4. **원본으로 되돌리기** → 브라우저 저장본을 지우고 파일 값으로 복귀

편집 대상은 **타자 / 투수** 두 개입니다 (선발·중계·마무리는 투수 점수표를 공유).

## 2. 포지션별 노출 규칙 — `data/positions.js`

선발/중계/마무리 탭에서 **그 포지션에 등장할 수 없는 스킬은 검색되지 않습니다.**
판정은 세 단계로 이뤄집니다.

1. **`POSITION_OVERRIDE`** — 스킬명 전체로 강제 지정 (최우선). 예외 처리용.
2. **`POSITION_TAGS`** — 스킬명에 박힌 배치 태그로 탭 결정.
   `마무리`→마무리, `불펜`→중계+마무리, `중계`·`필승조`·`셋업`·`추격조`·`롱릴리프`·`승리조`→중계, `선발`→선발.
   태그가 하나도 없으면 세 탭 모두.
3. **`POSITION_AVAILABILITY`** — 넥슨 공식 확률표(`스킬 변경권` 시트) 기준 등장 가능 포지션으로 교집합.
   출처: https://cpbv22-fn.qpyou.cn/cpbv22/push/chance/etc_260811.htm

공식표상 제한이 있는 스킬은 7개입니다.

| 스킬 | 등장 가능 |
|---|---|
| 첫단추 · 원투펀치 · 집념 · 좌승사자 | 선발만 |
| 라이징스타 | 선발 · 중계 |
| 마당쇠 · 원포인트릴리프 | 중계 · 마무리 |

그 결과 탭별 스킬 수는 **타자 83 / 선발 68 / 중계 75 / 마무리 64** 입니다.

### 어느 탭에도 안 보이는 스킬 3개

`마당쇠(선발)`, `원포인트릴리프(선발)`, `첫단추(불펜)` — 점수표에는 있지만 공식 확률표상 그 포지션에서
등장이 불가능한 조합이라 숨깁니다. 노출하고 싶다면 `POSITION_OVERRIDE` 에 추가하세요.

```js
window.POSITION_OVERRIDE = { "마당쇠(선발)": ["starter"] };
```

필터 자체를 끄려면 `window.POSITION_FILTER_ENABLED = false`.

## 3. 스킬 등급 색상 — `data/grades.js`

`data/batter.jpg` · `data/pitcher.jpg` 의 행 배경색 = 인게임 스킬 등급입니다.
이미지 픽셀을 분류해 넣었고 공식 확률표의 `등급` 열과 100% 일치합니다.

| 등급 | 글씨색 | 개수 (타자 / 투수) |
|---|---|---|
| 국가대표 | 주황 | 6 / 7 |
| 메이저 | 자홍 | 62 / 78 |
| 마이너 | 하늘 | 5 / 6 |
| 루키 | 초록 | 5 / 6 |
| 아마추어 | 회색 | 5 / 3 |

- 키는 **기준 스킬명**(괄호 앞에서 `☆★`·공백 제거). `긴급투입(추격조)☆` 와 `긴급투입(선발)☆` 는 `긴급투입` 하나로 처리됩니다.
- 목록에 없는 스킬은 `DEFAULT_SKILL_GRADE`(기본 `"특수"`)로 표시됩니다.
- 색은 `GRADE_COLORS` 에서 Tailwind 클래스로 바꿉니다 (라이트/다크 값을 함께 적음).

## 4. 확률 · 등급 기준 — `data/prob.js`

- `PROB_DATA` — `{ 점수: 확률(%) }`. 표에 없는 점수는 선형 보간, 최대 점수 초과 시 `이하` 로 표기.
  카드타입 키(임팩트/시그니처/골든글러브/국가대표/올스타)를 추가·삭제하면 버튼도 자동 반영됩니다.
  **올스타 값의 출처**는 `data/allstar_*.PNG` 이며 다음과 같이 가공했습니다.

  | 표 | 값 |
  |---|---|
  | batter | `allstar_batter` 의 좌타·양타·우타 **평균** |
  | pitcher | `allstar_pitcher` 의 좌투·우투 **평균** |
  | relief | `allstar_bullpen` 의 셋업·승리조·롱릴리프·추격조 **평균** |
  | closer | `allstar_bullpen` 의 **마무리** 열 |

- `PROB_TAB_MAP` — 탭이 어떤 확률표를 쓸지. 원본 사이트와 동일하게 **중계/마무리도 선발 표**를 씁니다.
- `PROB_TAB_MAP_BY_CARD` — 카드타입별 예외. **올스타만** 중계는 `relief`, 마무리는 `closer` 표를 씁니다
  (불펜 보직별 확률이 따로 있기 때문).
- **`FIRST_SLOT_FIXED_CARDS`** — "1옵션이 고정되는" 카드타입 목록 (기본 `["임팩트", "올스타"]`).
  여기에 적힌 카드는
  ① 확률·등급 계산에서 **1번 슬롯을 빼고 2·3번만** 합산하고,
  ② 등급을 확률이 아닌 **`GRADE_GUIDE.minScore`(점수 이상)** 으로 판정하며,
  ③ 중계/마무리 탭의 **-2 불펜 보정을 받지 않습니다.**
- `BULLPEN_PENALTY` — 그 외 카드에서 중계/마무리 탭 합계 점수 -2 (원본 로직). 끄려면 `tabs: []`.
- `GRADE_GUIDE` — 일반 카드는 `maxProb`(확률 이하), 1옵션 고정 카드는 `minScore`(점수 이상)로 판정.
- `CARD_GUIDE` — 카드타입별 1옵션 권장 안내 문구. `{ "카드타입": { 탭id: "문구" } }` 형태라
  카드타입을 추가하면 그 카드에서도 안내가 뜹니다.

## 5. 계산 규칙

- **총 렙합 / 총 점수합**: 1·2·3번 슬롯 전부 합산 (표시용).
- **상위 확률 / 등급**: 일반 카드는 3슬롯 합산 점수로, **임팩트·올스타는 2·3번 슬롯만** 합산해 계산합니다.
- **중계/마무리 탭**은 임팩트·올스타가 아닐 때 합계에서 2점을 뺀 값으로 확률을 구합니다.
- **등급**: 임팩트·올스타는 점수 기준(`minScore`), 그 외는 확률 기준(`maxProb`).
- **스킬변경권**: `올림(100 ÷ 확률%)` 개. 임팩트는 `일반스킬변경권`, 그 외는 `고급스킬변경권`.

## 5-1. 올스타 확률표 (페이지 하단)

`data/allstar.js` 의 표 3종(타자 / 선발 / 중계)이 하단에 접기·펼치기 형태로 표시됩니다.
`columns` 와 `rows` 만 고치면 되고, 배열에 항목을 추가하면 토글도 자동으로 늘어납니다.
값은 화면에 그대로 찍히는 문자열이라 `0.0050` 처럼 원본 자릿수를 그대로 유지할 수 있습니다.
